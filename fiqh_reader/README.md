# قارئ الفهرس الحقيقي — «الفهرس الحقيقي بالقراءة»

موقع ثابت لقراءة محتوى الكتب الفقهية المفهرسة (21 كتاباً): لكل كتاب شجرة وحداته الحقيقية (كتب ← أبواب ← فصول/مسائل) ونص كل وحدة كاملاً مقصوصاً حرفياً من نسخة الشاملة، مع ذراتها وموضعها (ص N).

## التشغيل

- مباشرة: افتح `index.html` في المتصفح (يعمل على `file://` — بيانات الكتب تُحمَّل عبر وسوم `<script>`).
- أو خادم: `python3 -m http.server --directory indexes/fiqh/reader` ثم `http://localhost:8000`.

## التوليد

`python3 tools/build_reader.py` — ينتج `data/index.js` (فهرس الكتب) + `data/<slug>.js` (وحدات الكتاب كاملة النص). تعتمد على `out/<slug>.extract.json` من `extract_real.py`.

## المزايا

- اختيار الكتاب من الشريط العلوي (ملوّن بالمذهب)، تحميل كسول للبيانات.
- بحث فوري في العناوين والنصوص بتطبيع الهمزات/التشكيل.
- روابط عميقة: `#<slug>/<unit_i>` لأي وحدة.
