# RULES — قواعد إلزامية للوكيل الجديد (كل قاعدة اشتراها المالك بخطأ)

## قبل أي بناء — إلزامي
1. **جرد الموجود أولاً:** لا تكتب سطراً قبل أن تفتح الأصول الجاهزة وتثبت سلباً «هذا غير موجود». الفهرس: `mac_index.jsonl` (5820 سجلاً) + wahy/rlg/akidsofi/des. **أرفق تقرير الوجودة بالخطة قبل التنفيذ.**
2. **لا تبنِ نظاماً مكرراً:** 8+ أنظمة تعلم ذاتي على Desktop ماك — grep الفهرس قبل أي بناء.
3. **الخدمات الجاهزة = قواعد بيانات لا تحتاج شيئاً:** التفسير (wahy) والفقه (rlg) والحديث (sunnah/islamic.app) مقطّعة أصلاً — لا تعيد التقطيع.
4. **عينة قبل تعميم:** سلسلة/كتاب واحد يُعرض على المالك قبل أي توسع كمي — لا توسع بلا قبوله.
5. **إفصاح قبل صرف:** سطر واحد «سأعمل X لأن Y» قبل أي عمل ثقيل — المالك يوقفك إن جانبتَ.

## حول الأدوات — مُثبت بالتجربة
6. **لا افتراض API:** جرّب خطأً واحداً بيدك (جسم الاستجابة الحقيقي) قبل تعميمه. 429 Gemini = RPM لكل مشروع×نموذج لكل دقيقة (retryDelay ~40s) — **ليس** نفاداً يومياً. مفتاح «محروق» قد يعمل على نموذج آخر.
7. **تفريغ الصوت = مقاطع دقيقة:** ffmpeg `-f segment -segment_time 60 -c copy` ← طلب generateContent لكل مقطع 60s ← `cat` مرتبة للدرس. **ممنوع طلب ملف كامل.** النماذج المقبولة: `gemini-3.7-flash` و`gemini-3.8-flash` بالتعاقب.
8. **المخرجات:** `transcripts_agy/<series_dir>/<basename>.txt` — التحقق = ملف غير فارغ + agy_done.txt.

## حول الذاكرة — السبب الجذري لكارثة الليلة
9. **ذاكرة خارجية إجبارية:** حدّث `handover/WORLD_STATE.md` كل دورة (إيش موجود/تم/قيد العمل). إن نسيت شيئاً اقرأ الملف — الجلسة تنسى، الملف لا.
10. **تقارير مجمعة:** العمال يكتبون لملف/كانفس، المدير يقرأه دورياً — **ممنوع** رسالة-برسالة للمدير (حرقت سياق المدير السابق).

## قواعد دائمة من المالك
11. **لا تصفّر إجابات المالك أبداً** — ans_guard + seed_tick يعملان دائماً؛ إيقافهما محرم.
12. **كل شيء تحت `des/`** — ريبو واحد حاكم. فرع الشغل `durus-site`، النشر `main`.
13. **العربية، اختصاراً، صدقاً:** إن لم تعمل شيئاً قل «لم يعمل» — لا تدّعِ نجاحاً.
14. **المدير يدير ولا يكتب ميزة:** توزيع فقط؛ السكربتات التشغيلية (ffmpeg/curl مقاطع) مسموحة.
