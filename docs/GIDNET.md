# GIDNET — شبكة المعنى

`hadith/analysis.js` (يُقدَّم على `/des/hadith/analysis.js`) — أثر بناء ليلي (nightly build) يولّده
`wahy/analysis/build_gidnet.py` من حزم `wahy/data/hadith/*-det.json.gz` و
`topics.json.gz`. يُحمَّل بوسم سكربت ويعرّض كائناً واحداً `window.GIDNET`.

```html
<script src="analysis.js"></script>  <!-- من صفحة داخل hadith/ -->
```

## البنية العليا

```js
GIDNET = {
  meta:  {...},              // معلومات عامة (كتب، إحصاءات، خريطة الحقول)
  g:     {gid: {...}},       // 5889 مجموعة معنى موحدة — مفتاح العمل
  rawi:  [name, ...],        // جدول الرواة: rawi_id → الاسم الكامل (6384)
  t:     {tid: {n, p}},      // شجرة الموضوعات: الاسم + الأب (24748)
  tg:    {tid: [gid]},       // الموضوع الورقي → معانيه (14491)
  cov:   {tid: {sa,mx,zu}},  // التغطية الطبقية لكل موضوع ورقي
}
```

## `GIDNET.g[gid]` — مجموعة المعنى

| حقل | المعنى |
|-----|--------|
| `t` | طرف المعنى المشترك (نص مختصر موحد) |
| `h` | حكم المعنى الموحد: صحيح/حسن/ضعيف/شديد الضعف/متهم بالوضع/موضوع |
| `s` | `sahaba_qty` — عدد الصحابة الذين رووا المعنى |
| `r` | `repeat_qty` — عدد مرات ورود المعنى في الأمهات |
| `w` | `{كتاب: [أرقام]}` — كل مواضع وقوع المعنى في الكتب الستة |
| `x` | `{كتاب: رقم}` — أول رقم حديث لكل كتاب (إحالة سريعة؛ مُعاد بناؤه من `hs` لأن `x` المصدر جزئي) |
| `j` | `{كتاب: {رقم: [حكم_سند,...]}}` — نصوص أحكام كل الأسانيد للحديث |
| `n` | `{كتاب: [rawi_id,...]}` — الرواة عبر كل أسانيد مواضع الكتاب، مرتبة ظهور، بدون تكرار وبدون العقد الصورية («موضع تعليق/إرسال/انقطاع») |

مثال (`gid=319` — الأعمال بالنيات):

```js
GIDNET.g["319"] = {
  t:"إنما الأعمال بالنيات ...", h:"صحيح", s:5, r:235,
  w:{bukhari:[1,53,2356,...], muslim:[3537], tirmidhi:[1569],
     "abi-dawud":[1885], nasai:[74,3401,3757], "ibn-majah":[4225]},
  x:{bukhari:1, muslim:3537, tirmidhi:1569, "abi-dawud":1885, nasai:74, "ibn-majah":4225},
  j:{bukhari:{"1":["إسناده متصل ، رجاله ثقات ، رجاله رجال البخاري", ...]}, ...},
  n:{bukhari:[0,1,2,...], ...}   // rawi_ids ← GIDNET.rawi[id]
}
```

## `GIDNET.cov` — التغطية الطبقية (منهج الشامي)

تصنيف طبقات الزوائد مطبقاً على الكتب الستة (طبقتا الموطأ/المسند غائبتان من
المدخلات — المدخلات الكتب الستة فقط):

| مفتاح | الطبقة | الشرط | العدد |
|-------|--------|-------|------|
| `sa` | معتمد على الصحيحين فقط | في بخاري/مسلم وليس في أي سنن | 714 |
| `mx` | في الصحيحين ومُسند على السنن | في الصحيحين وسنن معاً | 1976 |
| `zu` | زوائد — في السنن فقط | سنن أربعة فقط، لا وجود في الصحيحين | 3199 |

`cov[tid]` معرّفة على **الموضوعات الورقية** فقط (حيث تُسنَد الـgids)؛ لتجميع
مستويات أعلى: امشِ في `t` صعوداً/نزولاً ووحّد القوائم.

### أنماط الاستعمال للـfrontend

```js
const NET = GIDNET;

// نص المعنى + حكمه لأي حديث:
const g = NET.g[gid];                      // ← من d[num].g في بيانات الكتاب
const hukm = g.h, taraf = g.t;

// مواضع المعنى في الكتب:
for (const [book, nums] of Object.entries(g.w)) { /* روابط الكتاب/الرقم */ }

// شبكة الرواة للمعنى (أسماء):
const names = g.n["bukhari"].map(i => NET.rawi[i]);

// تغطية طبقية لموضوع:
const c = NET.cov[leafTid];                // {sa:[],mx:[],zu:[]}
```

## إعادة التوليد

```bash
cd wahy/analysis
python3 build_gidnet.py                          # يقرأ ../data/hadith محلياً
python3 build_gidnet.py -o analysis.js           # نفس النتيجة
python3 build_gidnet.py --base-url https://medmrf-10.github.io/des/wahy/data/hadith
```

بدون اعتماديات — Python 3.9+ فقط. الناتج الحالي: 5889 gid، 6384 راوياً،
~12.8MB (الخادم يضغطه gzip تلقائياً عبر الشبكة ~2-3MB).
