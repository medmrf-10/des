# تفسير بالطلب — مرحلة ١

خدمة FastAPI رفيعة تردّ على `(سورة، آية، tafsir_id)` بنص التفسير المقصوص حرفياً، فوق [spa5k/tafsir_api](https://github.com/spa5k/tafsir_api) مستضافاً ذاتياً (57 طبعة عربية).

## التشغيل

```bash
./setup.sh            # يجلب البيانات ويستخرجها إلى data/tafsir_api-main/ (~5GB)
uvicorn app.main:app --port 8377
```

- واجهة عربية: `http://127.0.0.1:8377/`
- `GET /tafsir/{slug}/{surah}/{ayah}` ← `{edition, surah, ayah, ayahs[], grouped, text}`
- `GET /editions` — الطبعات + التغطية لكل واحدة
- `GET /coverage` — جدول التغطية كاملاً (6236 آية مرجعية)

المقاطع المجمعة (نصّ واحد يغطي آيات متتالية) تُعاد مرة واحدة مع `ayahs` قائمة بمداها — مثال: سعدي `1/3` ← آيات `[1-7]`، ابن كثير `2/8` ← `[8,9]`.

## الفحص

```bash
TAFSIR_DATA=$PWD/data/tafsir_api-main/tafsir python3 verify.py
```

426+ استعلاماً عبر كل الطبعات؛ كل ردّ يُقارن حرفياً بملف المصدر. الخروج 0 ⇐ صفر اختلاف. الـ404 مسموحة فقط لآيات غير موجودة في الطبعة (طبعات جزئية التغطية مثل ضوء البيان وابن عثيمين).

## حدود معروفة

- طبعة الجلالين المصدرية فيها انقطاع نصي علوي (2:81 منتهية نصف جملة، 2:82 غائبة) — عيب البيانات لا الخدمة، موثّق في `/coverage`.
- متغير `TAFSIR_DATA` يحدد جذر البيانات (الافتراضي `data/tafsir_api-main/tafsir`).
