# xlink — جسر الذرات ↔ الفهرس

يربط بنك الذرات (`jadid2/atoms/*/index.json`, 5254 ذرة / 35 سلسلة)
بشجرة الفهرس الموحّد (`jadid2/fihris`, 88 عقدة + ملحق، علمها الحالي: أصول الفقه).

## الملفات

| الملف | الوظيفة |
|---|---|
| `tools/map_atoms.py` | الأداة + قاموس التطبيع الموثّق (`ALIAS`) وقواعد العنوان (`TITLE_RULES`) والروابط اليدوية (`MANUAL`) وسقالات العقد المقترحة (`PROPOSED_TREES`) |
| `data/atom_links.json` | الخراطة الكاملة: `{atom → {node, via, confidence, matched, proposed}}` |
| `data/coverage.md` | تقرير التغطية لكل عقدة + العقد اليتيمة |
| `PROPOSED_NODES.md` | الفرعيات اليتيمة مجمّعة تحت عقد `p.*` مقترحة |
| `SAMPLE.md` | تحقق نصي يدوي من 3 عقد + روابط رُفضت عمداً |

## النموذج

- `via ∈ {manual, tag-normalized, title-match}` — تفصيلها في ترويسة الأداة.
- `confidence ∈ [0,1]`؛ <0.6 = إشارة موضوعية لا ربطاً مؤكداً.
- **قاعدة النطاق**: الفرعية تُطابَق داخل علمها فقط (`النطاق, الفرعية المطبَّعة`).
- `node=null` + `proposed=p.*` = لا نظير في الشجرة — لا يُحشَر قسراً.

## التحديث

`python3 jadid2/xlink/tools/map_atoms.py` من جذر الريبو — بلا اعتماديات.
القاموس هو وحده ما يُحرَّر يدوياً؛ الخرج كله مشتق.
