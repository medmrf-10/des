# تقرير المصادر المفتوحة — jadid2/oss
**الغاية:** بنية تحتية تُبنى عليها المنصة — كل ما يوفر أشهر عمل جاهزاً مُقيّماً.

## A. بيانات المصادر النصية (جوهر نظام «آية+كتاب→مقطع»)

### 1. meibassam/mosahaf-tafseer — منزّل ✓ (133MB)
- **ماذا:** 114 ملف JSON (ملف/سورة) — كل آية: رقمها + نصها + مصفوفة تفاسيرها.
- **8 تفاسير كاملة:** الميسر، الجلالين، السعدي، ابن كثير، الوسيط طنطاوي، البغوي، القرطبي، الطبري — 6236 آية محققة العدد.
- **القيمة:** العمود الفقري الجاهز لنظام «آية + اسم كتاب → المقطع الدقيق» — المهمة تصبح قراءة JSON لا استخراجاً من نص خام. دقة عالية (تقسيم ابن كثير القياسي).

### 2. AhmedBaset/hadith-json — منزّل ✓ (176MB)
- **ماذا:** 50,884 حديثاً من 17 كتاباً — الكتب التسعة + الموطأ + مسند أحمد + رياض الصالحين + الشمائل + بلوغ المرام + الأدب المفرد + مشكاة المصابيح + الأربعينات الثلاث.
- **الشكل:** JSON منظّم (عربي+إنجليزي+الراوي) بمخططين: by_book وby_chapter.
- **القيمة:** نفس معادلة التفسير للحديث — «حديث/رقم+كتاب→نص» يصبح lookup مباشراً.

### 3. OpenITI (github.com/OpenITI) — مرجع عميق (لم يُنزّل كاملاً عمداً)
- **ماذا:** أكبر كوربوس إسلامي آلة-مقروء عالمياً (+40 ألف نص من الشاملة والمكتبات الأخرى بصيغة mARkdown مهيكلة بفهارس TOC).
- **القيمة:** عندما نريد «كتاب فلان بنص موثّق» — المصدر الوحيد الجاد. مستودعاته عملاقة (تنزيل انتقائي لكل كتاب لا نسخة كاملة).

## B. محرك التكرار المتباعد للمهارات (جوهر L08)

### 4. open-spaced-repetition/py-fsrs — منزّل ✓ (1.3MB)
- **ماذا:** تطبيق FSRS-5/6 الرسمي بلغة بايثون — المرجع نفسه الذي بُني عليه أنكي.
- **القيمة:** فكرة تطبيق التكرار المتباعد على **المهارات** لا المعلومات فقط: الحالة لكل بطاقة (difficulty/stability/retrievability) قابلة للتوسع على تمارين مهارية — نغذّيها نتيجة التمرين فيجدول المراجعة التالية. API نظيف، MIT.

### 5. open-spaced-repetition/fsrs4anki — منزّل ✓ (52MB)
- **ماذا:** تطبيق أنكي المرجعي + **optimizer** يضبط المعايير الـ19 على سجل مراجعات المتعلم الحقيقي.
- **القيمة:** لاحقاً — بعد أشهر من بيانات مراجعات محمد — يحسب معاييره الشخصية بدل الافتراضية (تخصيص جادولته على نسيانه الحقيقي).

## C. الإنجليزية — الإدخال المفهوم i+1 (جوهر مسار كراشن)

### 6. lexweave-hq/lexweave — منزّل ✓
- **ماذا:** محرك «graded reader» تكيفي — يُكمل نصاً مرة واحدة إلى «verbatim spans» (مواضع مطابقة نصية دقيقة!) ثم يولّد نسخة متدرجة لكل قارئ عند القراءة، وحالة المتعلم خارج الأصل.
- **القيمة:** نفس عقد الذرات عندنا حرفياً (مقاطع نصية موثّقة + حالة متعلم منفصلة + تكييف i+1) — إثبات معماري أننا على الطريق الصحيح، وطبقة سياسته (replacement planner/flow budget) قابلة للاقتباس لنظام «النص المتكيف مع مستوى محمد».

### 7. Destaq/linguakite — منزّل ✓
- **ماذا:** قارئ مدرّج ببنك كلمات شخصي: تظليل تردد/معرفة، قاموس ونطق بنقرة، أسئلة متولدة، إحصائيات.
- **القيمة:** UX مرجعية لقارئ i+1 الإنجليزي — بنك المفردات + % معروفة + قياس تقدم القراءة.

## الخلاصة التنفيذية
- «آية+كتاب→مقطع» للتفسير والحديث: **لم يعد مشروعاً — مصادره منزّلة ومهيكلة** (بند A1+A2).
- FSRS-للمهارات: **py-fsrs يكفي للمحرك**؛ fsrs4anki-optimizer لمرحلة التخصيص.
- الإنجليزية: **lexweave = النموذج المعماري المرجعي** لعقد «أصل مهيكل + حالة خارجية + تكييف» الذي نبنيه.
